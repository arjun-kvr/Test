# insights-reader

a read-only MCP server that lists the views in the insights schema of a PostgreSQL database and runs read-only SELECT queries on them, for agents that report on platform usage.

Generated by the AgentOS **MCP Builder**. FastMCP server, streamable HTTP
transport, listening on `8000` at `/mcp`.

## Tools

| Tool | Description |
|---|---|
| `test_connection` | Verify that the provided PostgreSQL credentials are valid and the database is reachable by performing a simple SELECT 1. |
| `list_schemas` | List non-system PostgreSQL schemas visible to the caller (optionally restricted by schema_filter). |
| `list_tables` | List relations in a schema (tables and/or views). Intended for discovering available insights views so agents do not guess names. |
| `describe_table` | Return column names, data types, nullability, and ordinal positions for one table or view. |
| `execute_query` | Run a read-only SELECT/WITH query (intended for insights schema reporting) and return rows capped by max_rows. |

## Authentication

Every tool call must carry a valid AgentOS platform session in the
`login-token` header. The middleware in `app.py` resolves the handle in the
platform's login Redis, verifies the RS256 session JWT (signature, expiry,
issuer, audience, handle binding) and admits only the Super Admin / Admin /
Pro code developer roles. Without a valid session, tools are neither listable
nor callable. **Do not remove the middleware** — an unauthenticated MCP server
fails security review and will be denied deployment.

Runtime needs (provided by the platform deployment):
`agentos-jwt-public-key` mounted at `/app/conf/keys` (public key ONLY — never
the platform's signing-key Secret) and
`REDIS_HOST` / `REDIS_PORT` / `REDIS_USERNAME` / `REDIS_PASSWORD`. Missing
either → the server starts and denies every call.

## Configuration

Only server-process settings come from the environment. **The entire
datasource connection — host, port, database, user, credentials — arrives as
tool parameters on every call**, injected by the platform from the configured
datasource. This server holds no connection details and no secrets, and one
deployment serves any number of datasources.

| Variable | Required | Description |
|---|---|---|
| `MCP_HOST` | no | Bind address (default `0.0.0.0`) |
| `MCP_PORT` | no | Port (default `8000`) |
| `JWT_PUBLIC_KEY_PATH` | no | Platform JWT public key (default `conf/keys/kivor_ai.pub`) |
| `REDIS_HOST` / `REDIS_PORT` | yes | Platform login-session Redis |
| `REDIS_USERNAME` / `REDIS_PASSWORD` | yes | Credentials for that Redis |
